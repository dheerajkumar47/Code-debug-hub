# BidSmith: Personal AI Bid Agent for Freelancer.com

A personal assistant that finds Freelancer.com projects that match your profile, scores each one for fit,
writes a tailored proposal grounded in your real portfolio, suggests a price and delivery period,
and places the bid **after you approve it on Telegram**.
